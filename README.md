# 🍭 祝小秋 · 零食自由

一份专属于「小秋」的零食自由祝贺网页 —— 甜甜的认证书、零食图鉴、随机快乐抽取和撒花特效。

## ✨ 特性

- **移动端优先**：手机、平板、桌面自适应
- **撒花特效**：Canvas 彩带，点击即撒
- **零食图鉴**：18 种零食卡片，点哪份领哪份
- **随机快乐**：手气抽取今日份零食 + 祝福语
- **计数记忆**：领取份数本地保存（localStorage）
- **纯静态**：无需后端，托管于 GitHub Pages

## 🚀 访问

在线地址：<https://celineluna.github.io/snack-freedom/>

## 🛠 技术

纯 HTML + CSS + 原生 JavaScript，零依赖。

```
index.html   # 页面结构
styles.css   # 样式与动画
script.js    # 交互逻辑
```
